Claude Code / Codex 接任意网关

填三行配置、跑一条命令,把终端里的编码 agent 接到你自己选的任何 API 网关。不绑定任何一家。

上手(30 秒)

git clone https://github.com/zhenhuaw404-ux/claude-code-any-gateway.git
cd claude-code-any-gateway
cp config.example .env     # 填三行:网关地址 / Key / 模型名
./run.sh                   # 启动 Claude Code
./run-codex.sh exec "say ok"   # Codex

配套页面

Cherry Studio 一键接入生成器 →粘贴你的 Key,生成一条链接,点一下就把服务商配好(离线运行,Key 不出本机) Cherry Studio 使用指南 →从建账户、充值到跑通、选模型、报错对照 看仓库 / 提问题 →源码、常见报错对照表、其它网关的填法
独立工具,与 Anthropic、OpenAI 无关联 · 请求发往你在配置里填写的网关
