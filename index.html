一条命令,把 AI 客户端接到任意网关

终端里的编码 agent(Claude Code / Codex)一条命令接上;图形客户端只填两个字段。不绑定任何一家服务。

30 秒上手

git clone https://github.com/zhenhuaw404-ux/claude-code-any-gateway.git
cd claude-code-any-gateway
cp config.example .env     # 填三行:网关地址 / Key / 模型名
./run.sh                   # Claude Code
./run-codex.sh exec "say ok"   # Codex

你用什么客户端?三种情况都覆盖

① 终端里的编码 agent(Claude Code / Codex) 用仓库里的脚本:一条命令设好接口地址、Key、模型;只在本次运行生效,不写进你的全局配置 ② 任何 OpenAI 兼容的图形客户端 NextChat · Chatbox · LobeChat · Open WebUI · Cherry Studio …… 任何 OpenAI 兼容的客户端做法都一样,只填两个字段:
接口地址 https://你的网关/v1 + 你的 Key;模型名写完整 ID。各网关怎么填见 providers.md ③ 已经在接、但老报错 报错对照表:401 无效 Key / 402 余额 / 403 未开通 / 404 模型名 / 429 限流 / 400 不支持工具调用 / 地址写错

三个必踩的坑(先看能省半小时)

坑怎么回事
模型名写简称deepseek-chat 会 404;必须写完整 ID(带厂商前缀),例如 deepseek/deepseek-v4-pro
用不支持工具调用的模型跑 Agent写作、角色扮演类模型(名字带 magnum、dolphin 这类)不支持工具调用,一用就报 400
余额为 0多数网关是预扣计费,余额为 0 时连免费模型也会返回 402
偏好图形界面?上面第 ② 条那两个字段填好即可,所有 OpenAI 兼容客户端通用。
另外,clients/ 目录里收录了几个客户端的专属配置助手(目前有 Cherry Studio 的一键配置生成器,后续按需增加)——它们都只是"少填几个字段"的便利工具,不是必须。
独立工具,与 Anthropic、OpenAI 及各客户端项目无关联 · 请求发往你在配置里填写的网关
