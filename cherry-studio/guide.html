接入指南

在 Cherry Studio 里使用 deCloud

一个 API Key,调用全球多种 AI 模型 —— 连同图像、视频、语音在内,账单都在一个地方

这份指南带你把 deCloud 接到 Cherry Studio 上。第一次用大约 5 分钟,分三步:准备账户 → 生成 API Key → 填进客户端。

开始之前:你需要一个钱包和一点余额

deCloud 用钱包签名登录 —— 不需要注册账号、不需要邮箱,连上钱包就是你的账户。支持 MetaMask、OKX Wallet、TokenPocket、imToken 以及浏览器钱包。

两个前提,缺一不可:
  1. 控制台里创建一个 API Key(下面第 2 步教);
  2. 账户里要有余额 —— 余额为 0 时,连免费的模型也会被拒绝(返回 402)。所以请先在控制台按提示充一点,够你试跑就行。

三步接入

1

进控制台,连接钱包

约 1 分钟

打开 https://macdecloud.com → 右上角 连接钱包 → 选一个钱包并签名确认。

连上之后就能看到你的账户、余额和用量。如果余额是 0,在这里按页面提示充值(控制台里提供了跨链向导,支持从 BNB Smart Chain 转入)。

跨链操作有风险,请仔细核对目标地址和数量 —— 交易一旦确认无法撤销。先充一小笔,够跑通就行。
2

创建一个 API Key

约 1 分钟

在控制台里找到 API Keys → 新建一个,复制出来。它会是一串 dcld-sk- 开头的东西。

  • 这串 Key 就是你的凭证,别发给别人、别写进代码仓库;怀疑泄露就在控制台里重新生成一个;
  • 同一个账户可以建多个 Key(比如给不同设备/项目各一个)。
3

填进 Cherry Studio

约 2 分钟

有两条路,任选一条。

方式 A:一键接入(推荐)

  1. 打开自助工具页:一键接入生成器,把你的 Key 粘进去,点「生成接入链接」;
  2. 先把 Cherry Studio 窗口打开、放在最前面(重要:这条链接不会自动把窗口调到前台);
  3. 点生成出来的那条链接(或复制后粘到浏览器地址栏回车);
  4. Cherry Studio 会跳到「设置 → 模型服务商」,弹出确认框:「是否要为 deCloud 添加 API 密钥?」 → 点确认;
  5. 列表里出现 deCloud → 点右边的「获取模型列表」→ 选一个模型就能用了。

方式 B:手动填(任何 OpenAI 兼容客户端都一样)

  1. Cherry Studio → 设置 → 模型服务商 → 添加(不是编辑内置的“OpenAI”那一项);
  2. 类型选 OpenAI(或“OpenAI 兼容”);
  3. 名称随便填(建议 deCloud);
  4. API 地址填 https://macdecloud.com/v1(要带 /v1);
  5. API 密钥填你的 Key;
  6. 点「获取模型列表」→ 选一个模型 → 开始对话。
别把我们的 Key 填进内置的「OpenAI」那一项:它的地址固定是 api.openai.com,会报“密钥不正确”。请务必新加一个自定义服务商。

选哪个模型

你的场景推荐
日常对话、写作、翻译deepseek/deepseek-v4-pro(便宜、上下文大,通用首选)
要跑 Agent / Claude Code —— 会自动调用工具的功能deepseek/deepseek-v4-pro · deepseek/deepseek-v4-flash · moonshotai/kimi-k3 · z-ai/glm-5.2 · qwen/qwen3-coder · anthropic/claude-sonnet-4.5 · openai/gpt-5
生成图片 / 视频 / 语音在 模型页按类型筛选;调用方式见文档
一个要点:Agent、Claude Code 这类功能靠“工具调用”干活,所以要选支持工具调用的模型。写作、角色扮演类模型(名字里带 magnum、dolphin 这类)不支持工具调用,选了会报 400。

常见报错对照

返回含义怎么办
401Key 无效检查有没有多空格、前缀是否完整
402余额不足去控制台充值(余额为 0 时,免费模型也会被拒)
403该模型未开通 / 额度用尽换个模型试试
404模型名不存在模型名要写完整 ID(带厂商前缀),例如 deepseek/deepseek-v4-pro
429请求太频繁等几秒重试(免费模型更容易遇到)
400 + upstream provider rejected该模型不支持这类请求多半是模型不支持工具调用 —— 换成上表推荐的那几个
地址一定写全:https://macdecloud.com/v1。要带 /v1,但末尾不要自己再加 /chat/completions —— 客户端会自己补。

其它客户端

只要是支持 OpenAI 兼容接口的工具都能接:NextChat、Chatbox、LobeChat、Open WebUI,以及 Claude Code、Codex 等命令行工具。填法都一样 —— 接口地址 https://macdecloud.com/v1 + 你的 Key。具体配置可查看官网的「客户端」页面。
