Cherry Studio:一把 Key,不必一家家注册账号

加一个服务商、填一个地址,就能用上多家模型 —— 想换哪家,改这一处就行,不用卸载重装。

先拿到那把 Key

  1. 连钱包登录:打开 macdecloud.com → 点「连接钱包」→ 签个名就进去了。不用注册账号、不用邮箱;签名只证明钱包是你的,不转账、不花手续费。
  2. 领体验额度:把控制台里你登录用的那个钱包地址发给客服 —— 微信公众号「deCloud」留言即可,会给你开体验额度。
    这一步不能跳:余额为 0 时,连单价为 0 的免费模型也会被拒(返回 402)。发地址时别发错 —— 要的是你登录用的钱包地址,不是充值页里那个「充值地址」(那是平台收款地址,认不出你是谁)。
  3. 建一个 API Key:控制台 → API Keys → 新建 → 复制。一串 dcld-sk- 开头的东西,只完整显示一次;别写进代码、别截图外发。

接进 Cherry Studio

两条路,选一条就行。

方式 A:一键接入(推荐,最少手填)

  1. 打开这个网页:一键接入生成器,把上面那把 Key 粘进去,点「生成接入链接」;
  2. 先把 Cherry Studio 打开、放在最前面 —— 这条链接不会自动把窗口调到前台,所以它得先醒着,否则看起来像"点了没反应";
  3. 点生成出来的那条链接(或复制后粘到浏览器地址栏回车);
  4. Cherry Studio 会跳到「设置 → 模型服务商」并弹确认框:「是否要为 deCloud 添加 API 密钥?」 → 点确认;
  5. 列表里出现 deCloud → 点右边「获取模型列表」→ 选一个模型就能用了。

生成器在你自己的浏览器里跑,Key 不出本地、页面不联网。

方式 B:手动填(四步)

  1. 设置 → 模型服务商 → 添加(是"添加",不是编辑内置的那一项);
  2. 类型选 OpenAI(有的版本叫"OpenAI 兼容"),名称随便填,建议就叫 deCloud;
  3. API 地址填 https://macdecloud.com/v1(要带 /v1);API 密钥填你的 dcld-sk-…;
  4. 点「获取模型列表」→ 选 deepseek/deepseek-v4-pro → 开始对话。
别改内置的「OpenAI」那一项 —— 它的地址固定是 api.openai.com,会报"密钥不正确"。请新加一个服务商。

选哪个模型

一个实测踩过的坑:模型列表拉下来之后,默认选中的可能是个名字排序靠前的写作向模型(例如 anthracite-org/magnum-v4-72b)。它不支持工具调用,拿它跑 Agent 或 Claude Code 会报 400 the upstream provider rejected this request —— 手动把默认模型改成 deepseek/deepseek-v4-pro 就好。

日常对话、写作、翻译,用 deepseek/deepseek-v4-pro 就行(通用首选)。要跑 Agent / Claude Code,必须选支持工具调用的:deepseek/deepseek-v4-pro · deepseek/deepseek-v4-flash · moonshotai/kimi-k3 · z-ai/glm-5.2 · qwen/qwen3-coder。想先用免费的,nvidia/nemotron-3-super-120b-a12b:free 这类也行(免费档上游会限流,报 429 就等几秒重试)。
