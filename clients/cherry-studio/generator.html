一键接入 Cherry Studio

把你的 API Key 填进去,生成一条链接,点一下就能配好 —— 不用手动填地址和 Key

① 点下面这条链接(会把配置直接写进 Cherry Studio):

—

② 然后在 Cherry Studio 里:设置 → 模型服务商 → 找到 deCloud → 点「获取模型列表」→ 选一个模型 → 开始对话。

放心:这个页面在你自己的浏览器里运行,Key 不会上传到任何服务器(页面不联网;链接里的 Key 也只在你本机使用)。

用之前先确认两件事

  1. 装了 Cherry Studio 桌面版(Windows / macOS)。手机上、网页版都没有这个一键协议 —— 那种情况请看下面的手动配置。
  2. 先把 Cherry Studio 窗口打开、放在最前面,再点链接。它不会自动把窗口调到前台,否则你会以为"点了没反应"。

点完链接会看到什么

  1. Cherry Studio 跳到「设置 → 模型服务商」,弹出确认框:「是否要为 deCloud 添加 API 密钥?」 → 点确认;
  2. 左上角提示「成功为 deCloud 添加 API 密钥」,列表里出现 deCloud;
  3. 点它右边的「获取模型列表」,拉到模型后选一个(推荐见下)就能用。

选哪个模型

场景推荐模型
日常对话 / 通用deepseek/deepseek-v4-pro(便宜、上下文大)
要跑 Agent / Claude Code 这类会自动调用工具的功能deepseek/deepseek-v4-pro · deepseek/deepseek-v4-flash · moonshotai/kimi-k3 · z-ai/glm-5.2 · qwen/qwen3-coder · anthropic/claude-sonnet-4.5 · openai/gpt-5
要点:Agent / Claude Code 靠"工具调用"干活,所以要选支持工具调用的模型。写作、角色扮演类模型(名字里带 magnum / dolphin 这类)不支持工具调用,选了会直接报错。

没装 Cherry Studio?手动配置(任何 OpenAI 兼容客户端都一样)

项目填什么
服务商类型OpenAI(或"OpenAI 兼容")
API 地址 / Base URLhttps://macdecloud.com/v1(要带 /v1)
API Key你自己的 dcld-sk-…
模型名deepseek/deepseek-v4-pro(要写完整 ID)
注意:不要编辑客户端里内置的「OpenAI」那一项(它的地址固定是 api.openai.com,填我们的 Key 会报"密钥不正确")。请新加一个自定义服务商。

常见报错

返回含义怎么办
401Key 无效检查有没有多空格、前缀是否完整
402余额不足先去控制台充值一点(余额为 0 时,连免费模型也会返回 402)
403该模型未开通 / 额度用尽换个模型试试
404模型名不存在模型名要写完整 ID(带厂商前缀),例如 deepseek/deepseek-v4-pro
429请求太频繁等几秒重试
400
upstream provider rejected		该模型不支持这类请求多半是模型不支持工具调用 —— 换成上面推荐的那几个
deCloud · 自助接入工具 · 仅在你本机浏览器运行,不收集任何信息
